# Test Vectors for CUDA Verkle

This directory contains deterministic known-answer vectors generated by the locked Rust reference dependencies. The C++ field, commitment, and depth-1 tree test suites consume the corresponding JSON files directly. Curve vectors are retained for future point decoding coverage.

## Format

The vectors are JSON fixtures. Field and scalar hex strings are canonical 32-byte, big-endian values. The commitment fixture set includes boundary cases plus deterministic full-width random scalar vectors for cross-implementation differential testing. Compressed Banderwagon points are emitted in the reference library's 32-byte encoding.

## Regenerating Test Vectors

To regenerate the test vectors, use the Rust reference implementation included in `rust-reference/`.

```bash
cd ../rust-reference
cargo run --release -- generate
```

This will run the Rust executable against the dependencies pinned in `rust-reference/Cargo.lock` and overwrite the tracked fixtures. Review and commit the resulting JSON diff together with any generator change; the C++ tests deliberately fail if a required fixture is absent or malformed.
